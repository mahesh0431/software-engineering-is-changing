# Software Engineering Is Changing

Slides for a talk by Mahesh Palavalli on how AI is changing software engineering: how we build, what agents can take on, science, AI improving AI, alignment, and the skills engineers need.

**View the presentation:** https://mahesh0431.github.io/software-engineering-is-changing/

A single self-contained HTML file. Use the arrow keys or a clicker to move through it. Press **F** for full screen, **N** for speaker notes, and **P** for a presenter view with a timer.
